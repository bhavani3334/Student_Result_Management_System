# 🎓 Student Result Management System

## 📌 Overview

The **Student Result Management System** is a web-based application designed to simplify the management of student academic records. The system enables administrators to store student details, enter marks, calculate grades, and generate results efficiently, reducing manual work and improving accuracy.

---

## ✨ Features

✅ Student Registration and Management

✅ Secure Admin Login

✅ Add, Update, and Delete Student Records

✅ Enter and Manage Student Marks

✅ Automatic Grade Calculation

✅ Result Generation and Display

✅ Search Student Results

✅ User-Friendly Interface

---

## 🛠️ Technologies Used

* 🐘 PHP
* 🗄️ MySQL
* 🌐 HTML
* 🎨 CSS
* ⚡ JavaScript
* 🚀 XAMPP/WAMP Server

---

## ⚙️ System Workflow

1. 👨‍💼 Admin logs into the system.
2. 📝 Student details are added to the database.
3. 📚 Marks are entered for each subject.
4. 🧮 The system calculates total marks and grades.
5. 📊 Results are generated automatically.
6. 🔍 Students can search and view their results.

## 🚀 Installation

### 📥 Clone the Repository

```bash
git clone https://github.com/your-username/Student-Result-Management-System.git
```

### 📂 Move Project Folder

Copy the project folder into:

```text
xampp/htdocs/
```

### 🗄️ Import Database

1. Open phpMyAdmin.
2. Create a new database.
3. Import the provided `.sql` file.

### ▶️ Run the Project

1. Start Apache and MySQL in XAMPP.
2. Open your browser.
3. Navigate to:

```text
http://localhost/Student-Result-Management-System
```
